# 架构发明循环（invent→check→reflect→refine）

目标: 为"极低分辨率调色板精灵生成"发明一个**真正新、有机理支撑、能当 ICLR 方法核心**的架构。
方法: 每轮 = 我从机理发明候选 → 拆成可查的零件 → 开 subagent 查证 novelty → 回来据结果拼/换 → 下一轮。
终止条件: 找到一个"查证=开放 + 有机理 + 可小实验验证"的架构, 或跑满 5 轮仍无 → 收敛报告给用户。

## 已排除
- **全像素注意力**: 撞 PiT(ICLR'25)+ImageGPT; 且极小分辨率上卷积 UNet 反而赢注意力。双杀, 弃。

## 统一论点(收敛中)
极低分辨率调色板 regime 小到可近乎精确建模, 数据本质"离散+有序"; 正确方法 = **低噪声、离散有序、分解成(调色板+索引图)**的生成器, 同时打赢高方差优化式(SDS)与连续 RGB 前馈。

## ★ 收敛架构(Loop 1 产出): 有序调色板流形上的分解式离散扩散
**一句话**: 从文字直接联合生成 (每图调色板 P, 索引图 M); M 由"沿 OKLab 感知排序的学习调色板漂移"的离散扩散生成(非高斯噪声、非 RGB 再量化、非给定调色板)。
**机理三条腿(都有文献支撑, 见 iclr_route/derisk)**:
1. SDS 低分辨率塌(高方差) → 用低噪声离散过程, 不用连续优化。[去风险 GO]
2. 离散扩散差=丢颜色顺序(D3PM: 有序核 7.34 vs 无序 30.97) → 沿有序调色板漂移保住顺序。**顺带解释 v6f 失败(朴素分类=丢顺序)**。
3. 像素画真实结构=颜色预算+空间布局两因子 → 分解成 (调色板, 索引图)。
**与对手差异**: Five-Dollar(固定调色板)/PixDiff-PIG(连续+条件)/D3PM(全局词表)/SD-πXL(用户调色板+SDS) 均不同。
**诚实风险**: ①两零件各有近邻, 卖点是"组合+每图+OKLab有序", 增量风险需靠机理和实验压过; ②PixDiff-PIG 全文待终审; ③"新架构一定赢"未证, 需探针。

## 2026-09-06 cycle 3 RESEARCH: 调色板因子化去噪头(palette-factorised x0 head)
**动机**: 公平 FD 下唯一有效手段是 TV 损失(53.21→42.82, 且甜点极窄 w=0.3→46.57), 结构域 FD 也证明短板是"局部离散结构"(分片恒定/硬边/少色), 结构分解(两阶段)无效。→ 把"少色+分片恒定"做成**输出参数化的架构瓶颈**, 而非损失。
**机制(3 个 subagent 汇总)**: 连续高斯扩散不变; 去噪器输出改为 (a) 每像素对 K 个调色板槽的 logits + 1 个 alpha logit, (b) 每图调色板 P∈R^{K×3}(全局池化→MLP, 或软 k-means 质心); x0 = softmax(logits/τ)·P(透明处 RGB=-1), eps 由 x0 反推喂给现有 DDPM 采样器(.sample 兼容 sample_e.py/eval_probe.sh)。文献支撑: 分类期望作 x0 是 CDCD/Analog Bits 的标准做法(高噪声处期望=后验均值, 无表达力问题); x0 空间损失 + Min-SNR-γ(γ=5)是低维流形 x0 的正确选择(eps 损失在 t→0 放大 10³ 倍调色板误差, 会毁预训练特征); ColorCNN 的三件套防灰均值/防塌缩(逐像素置信度、槽使用率、直方图熵); ControlNet 零初始化/λ 混合 ramp 使第 0 步恰等于 v7。τ 随 t 调度无先例(可作为小贡献), 先用固定退火 + 置信正则按 ᾱ_t 加权。
**Novelty**: 最近的 SD-πXL(SIGGRAPH Asia 24) 用同一图像参数化(softmax 权重·固定调色板)但是逐图 SDS 优化, 调色板由用户给; PixDiff-PIG(25 预印, 不可得)调色板为 k-means 条件; ColorCNN 无扩散; CCDM/Gaussian-Softmax 扩散是固定类别 softmax 头。**"预测调色板+软分配作为连续去噪器 x0 参数化"未见发表**。声明措辞: 端到端学习的、可编辑的每图调色板潜变量 + 与扩散时间耦合的温度, 首个仅改输出头(非改前向过程)就让像素空间 UNet 在 12-24px 产出少色分片恒定精灵的方法。
**可行性/风险**: 新参数 <60k; 从 v7 微调 20k; 失败模式 = 调色板塌缩(使用率正则+监控唯一色数)、灰均值(置信正则、τ 下限、末步 argmax)、低 t 损失爆炸(x0-SNR 损失、零初始化、λ ramp)。若前 2k 步样本明显劣于 v7 → 立即停。
**决策 → BUILD probe_palhead**: src/v6/train_palhead.py(包装 UNet: conv_out→Identity, eps_direct 复制 v7 conv_out, logits 卷积 K+1, 调色板 MLP; λ 0→1 @4k, τ 1→0.3 @2k-10k; 损失 x0-SNR(γ=5)+0.1 调色板支路一致性+0.01 使用率熵+置信正则·ᾱ_t), sample_e.py 加 "palhead" 加载分支, 末步 t=0 硬分配。K=16。GPU2, eval_probe.sh probe_palhead 2 → DECIDE(<38/38-45/>45)。

## 2026-09-06 cycle 4 RESEARCH: 三路并行调研 + 控制实验 → 选定"投影入环自条件"(probe_selfq)
**起点证据**: 颜色维度被 tv+q16(35.24) 平凡解决; 剩余差距=局部离散结构(结构域 15.5 vs 地板 1.4); 学到的量化瓶颈(palhead)塌缩; 外部事后吸附有训练/测试不匹配。
**控制实验 (ctrl_down16.sh)**: 32px 生成 → 训练用 BOX to_tensor 压到 16: v7 **84.07**(原生 53.21), tv **52.82**(原生 42.82)。"由细到粗"不是捷径, 32px 生成本身并不更好, 且 BOX 混色正是反像素画的行为 → **候选 3 loop-F 前提被削弱, 降级**。
**调研 (a) 多分辩率联合一致性**: 最近 Matryoshka Diffusion(ICLR24, 嵌套并行去噪, avgpool 目标, 无跨尺度约束)、simple diffusion 多尺度损失(ICML23)、f-DM(ICLR23, 降采样作前向过程)、Relay/Edify Laplacian/Pyramidal Flow/DDNM 投影。"联合 16+32 去噪 + 学到的精灵感知选择型降采样一致性" 未发表(novelty 中), 但坑多: 16px 精灵没有真 32px 对应, BOX 混色, SNR 跨分辩率不匹配, 计算翻倍。结合控制实验 → 不投。
**调研 (c) 区域/图元生成**: ≤32px 上所有图元/路径/笔画方法(Im2Vec 28px, SPIRAL, DiffVG)都丢 1-2px 细节; 唯一在小图上清晰的 SD-πXL 靠逐像素 Gumbel 调色板 logits(与我们 palhead 家族同源, 已证在前馈里塌缩)。可行探针: 像素+邻接亲和通道联合(novelty 中)、Potts 引导采样(低-中)。作为**第二形态备胎**保留(亲和头可与 selfq 叠加)。
**调研 (b) 单模型局部结构机制**: Bit Diffusion 自条件(ICLR23: 上一步 x0 估计 stop-grad 拼回输入, p=0.5 置零; x0 预测在离散目标上远优于 ε), DisCo-Diff(ICML24, 全局离散潜变量), HART(ICLR25, 离散大局+连续残差), RIN 潜变量自条件, Edge-Preserving Noise(EG26), Projected Diffusion(NeurIPS24)+Restart(NeurIPS23), Token-Critic/DPC(ICLR23), REPA 家族(像素空间在 16px 不稳且 DINOv2 是我们的指标编码器→禁用)。**2023-26 没有任何论文给出 16px 单像素细节正确性的机制, 这个空位是空的。**
**选定机制 A: 投影入环自条件 (projection-in-the-loop self-conditioning)**: 连续 RGBA UNet 输入 4→8 通道, 额外 4 通道 = **非学习、stop-grad** 的 P(x̂₀): 逐图 k-means(K=16) 颜色量化 + 硬 alpha。训练 p=0.5 喂零/喂投影(Bit Diffusion 式, 需一次 no-grad 前向); 采样每步喂上一步的投影。损失不变(ε MSE + TV 0.1, 从 probe_tv 微调)。**机理**: 网络看到自己输出的硬边分片恒定假设并学会**修正**它, 而不是模式平均(v7)或被迫穿过可塌缩的学到瓶颈(palhead); P 不学习不进损失 → 不会塌; 投影在训练与采样两侧都在环内 → 消除事后吸附的不匹配(sgen 上色器死因)。
**Novelty**: 最近 Bit Diffusion 自条件(机制相似度高, 但作用于原始 x0/bits 而非调色板投影)、RIN(中)、Simple Self-Conditioning for MDMs 2026(中)。总体 **中**; 论文框架应是"离散假设入环"= A + **B(置信评论员选择性 restart: 逐像素头预测 P(x̂₀)是否等于 P(x₀), 采样时只对低置信像素重加噪)**, B 的 novelty 中-高(连续模型的像素选择性 restart 无先例)。A 有信号再加 B。
**坑**: 12px 上 K=16 全局调色板可能吞 1px 眼睛/轮廓(用逐图自适应 K-means 缓解, alpha 不投影); 自条件可能成吸引子(网络照抄 P) → 保持 p=0.5; 指标配对: 原始 vs 42.82(paired 对照 probe_tv_cont), +q16 vs 35.24。
**决定**: BUILD src/v6/train_selfq.py (SelfQUNet, kmeans_quantise, 采样入环), sample_e.py 加 selfq 分支, baseline/run_probe_selfq.sh; 冒烟 200 步通过(采样图≈probe_tv, 零初始化 conv 使起点等价)。GPU3 = probe_selfq 20k; GPU2 = **配对对照 probe_tv_cont**(probe_tv 同损失再训 20k, 隔离"多训 20k"效应)。

## 2026-09-06 cycle 5 RESEARCH: 三路调研汇总 + 诊断 → 重定问题
### 诊断先行(见 experiment_log cycle 5 ①②)
- FD 分解: 所有模型 precision≈0.89(地板 0.94), recall/coverage≈0.60(地板 0.92) → 差距=覆盖, 不是保真。
- prompt 匹配控制: probe_tv 42.82 → **28.02**; +q16 在 matched 下无效。旧协议 ~15 点是词表 prompt 错配伪影, "少色"叙事大半是伪影。协议已重定为 matched FD。
- CFG 扫描(旧协议): 1.5→74.7, 2→51.0, 4→42.8: 引导越弱越差(与 ImageNet 经验相反), 说明条件分支本身很弱、模型靠 CFG 硬撑。
- 指标本质(调研 c 指出): 16px NEAREST 放大到 224, DINOv2 patch=14 → **每个 patch 恰好=一个精灵像素的纯色块**, FD-DINOv2@16 = 在 16×16 颜色网格上的一个学习核; 它重罚孤立错像素(一个像素=一个错 token)、轮廓拓扑、逐像素颜色统计。12/24px 与 patch 网格错位 → 应按原生尺寸分层报。

### 调研 a: 逃离均值回归的训练目标(输出 p(x0|xt) 的样本而非均值)
- **DDM-SR 评分规则去噪器**(De Bortoli+ ICML25, 2502.02483): 输入拼噪声 ξ, 能量分数损失 L=E||x0−x̂(ξ)||^β − λ/(2(m−1))ΣΣ||x̂(ξj)−x̂(ξj')||^β, m≥2 次前向, 少步采样(≤16 步; 多步反而差)。CIFAR 5 步 8.5 vs 12。风险: ξ 被忽略退化成中位数回归; 需监控 E||x̂(ξ)−x̂(ξ')||。fit 5 / 微调易 5 / novelty 5。
- **UFOGen 式对抗 x0 精修**(2311.09257; Diffusion-GAN 噪声化判别器 2206.02262 稳小数据): 生成器=现 DDPM, 判别器 4 层 conv 看噪声化 x̂0, 损失 eps-MSE + hinge + R1。fit 4 / 5 / 5。风险: 判别器只学直方图+锐边, 与 MSE 锚拉锯成半色调。
- **SiD/DMD2 模式寻求蒸馏**(2404.04057): 3 份 UNet, 反 KL 天然模式寻求。风险: 跨 prompt 塌缩杀 recall(我们恰恰缺 recall) → 不合适。
- PMRF "均值→样本"流(2410.00418): 冻结 DDPM 输出当起点训小流。
- 分类式 CE 头(CDCD/Analog Bits): 期望仍是均值, 与已死的离散族最近 → 不投。
- 理论支撑: 确定性反向过程渐近收敛到条件均值(2403.02957) → 少步随机采样有理。

### 调研 b: 引导/采样 + AR 基线 + 像素画文献
- **Autoguidance**(Karras 2406.02507): 坏模型=同族更小/更少训练(1/16 训练步最优), 权重 1.8-2.4 平台; 无条件 FID 11.67→3.86; 与 CFG 可叠加(小 CFG 只管 prompt 贴合)。**CADS**(2310.17347): 条件嵌入加退火噪声, DeepFashion 10k 图 FID 16.4→7.7, **recall 0.02→0.48** — 与我们的 recall 症状最像。Guidance interval(2404.07724; FD-DINOv2 最优区间比 FID 更宽), APG(2410.02416, 降饱和 recall 0.48→0.62), CFG++, rescaled-CFG+ZTSNR(2305.08891), In-situ autoguidance(2510.17136, dropout 当坏模型, 零训练)。NoiseShift(2510.02307): 低分辨率下整条 cosine 调度"太吵"。2026 基准(2608.16786)警告: 无训练 CFG 变体并不稳定优于 CFG, 必须自己扫。全部 novelty=0, 只能当组件。
- 像素画文献: Coutinho&Chaimowicz GAN 系列(64px 角色, Inception-FID, 无扩散基线); SD-πXL; Sprite Sheet Diffusion; **PixDiff-PIG**(2025 workshop, 42k 精灵, OKLab TinyUNet + 调色板/索引图条件, FID 19.6 vs LDM 28.4 — 唯一声称客观指标赢扩散的, 但调色板是输入非生成)。**无人在 ≤16px 做过受控研究(调度/增广/评测)** → 论文可占。
- AR: 16px=256(+alpha) token, 光栅/RAR AR 用颜色码本无需 VQ, 30-60M transformer <1 GPU 天; 离散像素建模 FID 差距已基本关闭(2603.20155 CIFAR 6.4)。**"调色板优先 AR"(先生成 K 个调色板 token 再生成索引)未发表**——唯一新机制候选, 但属于已废"离散/少色族"的近亲, 且 matched 协议下颜色已不是问题 → 降为基线候选。

### 调研 c: 差距来源 / 数据规模 / 配方
- 72M 参数对 1024 维目标、30k 图: 过容量+欠泛化(Gu+ 2310.02664: 16×16 的记忆阈值 >4k 图; 近唯一 caption 像唯一标签, 把 0% 复制推到 65%)。→ 诊断: 生成样本到训练集 NN 距离 vs held-out 到训练集。
- CFG: Ho&Salimans ImageNet-64 scale 4 比 1.1 差一个量级; 但我们扫出相反方向(弱引导更差) → 条件分支弱是主因, 需 CADS/autoguidance 而非单纯降 CFG。
- 非泄漏增广(EDM App.F, p=0.15; 整数平移/翻转/OKLab 色相旋转, 增广参数作条件)对 ≤70k 数据是 EDM 的标配, ADA 拐点恰在 30k。
- 16px 调度: simple-diffusion 外推 logSNR 应 +2.8 nats(更少噪声); EDM P_mean −1.2→≈−1.9; **无人在 16px 研究过**。ZTSNR+v-pred 管全局均值(alpha 覆盖/主色)。EDM2 事后 EMA 扫描可解释 1-4 点 run 间方差。
- 评测: 加 KD/CMMD(MMD 置换检验给 ±4 差异 p 值), FD∞, 按原生尺寸分层, 真实数据"扰动标尺"(1-3% 杂点/色相偏移/1px 腐蚀 → 校准 FD 的单位)。

### 综合判断(待 matched 扫描出数后定 BUILD)
1. 论文的"新东西"可能不是一个去噪头, 而是**极低分辨率生成的系统性研究**: 评测协议(patch-对齐分析、匹配 prompt、扰动标尺、分层)、16px 专用调度/增广、覆盖问题的机制解(CADS/autoguidance/评分规则去噪)。这在 ICLR 上是"分析+方法"型论文, 前提是最终方法在 matched FD 上显著赢过 v7/probe_tv。
2. 机制候选优先级(按"直接打 recall/覆盖 + 可微调 + 未撞车"): ① **CADS + autoguidance(早期 ckpt 为坏模型)** 零训练, 先测(是组件, 决定基线的真实水平); ② **能量分数随机去噪器(DDM-SR 微调, ξ 通道 + 少步采样)** — 唯一从根上改变"输出均值"的可微调机制, 在像素画/极低分辨率未有人做; ③ 非泄漏增广 + 16px 移位调度 + ZTSNR 重训(配方, 作为强基线/组件); ④ UFOGen 式对抗精修(备胎)。

## 2026-09-07 cycle 6 RESEARCH: 自引导(Karras 2024)变体文献占位图 → 以自引导为核心的新机制候选

**起因**: v7h 上自引导(弱=同 run 10k EMA, w=2)11.33 vs 裸 21.98, 是本项目迄今唯一 −10 点级别的信号; 但它是已发表方法, 必须找它周围的空位。一名 subagent 综述 2024-06 → 2026-09 约 40 篇(表见其原文, 关键 ID 列于下)。

**已占位(别碰)**: 早期快照/小模型作弱模型(2406.02507; 2509.15267; 2602.14706); 推理时 dropout 作弱模型(2510.17136, **且被证明无效**); 模糊/裁剪输入(SAG 2210.00939, SWG 2411.10257); 错误/随机条件(ICG/TSG 2407.02687, CDG 2603.10780); **中间层辅助头联训作弱模型**(SGG-BR 2603.20584, IG 2512.24176 CVPR'26, SSG 2607.29122)— 均以"中间层=低频"为理由; 自适应引导权重(FBG 2506.06085, Learn-to-Guide 2510.00815, SOC 2505.19367)全是 CFG 的, 自引导的自适应权重只有推荐系统一篇; 频率分离引导(FDG 2506.19713 提升 recall); 引导入训练(MG 2502.12154, GFT 2501.15420)。像素画/精灵/≤32px 上的引导研究: **零**。

**空位(subagent 结论 + 我的判断)**:
1. **跨分辩率自引导**: 同一多分辩率模型, 同一 x_t, 但喂**更低分辩率的 bucket 嵌入**(或下采样-上采样的 x_t)当弱预测。Karras 兼容性条件天然满足(同权重同数据), 退化轴恰好是 16px 最要命的"像素间渗色/调色板混合/轮廓糊"。文献中无人做过跨分辩率条件引导(最近的是 TSG 扰动时间步嵌入)。**零训练可测, 已排队 dv7h3**(bucket:12/24/64, blur:2, shift; w=2/1.5)。反向对照(更高分辩率嵌入作弱模型 = bucket:64)理论上不该有效, 若 12 有效 64 无效则机制清楚。
2. **学习的退化分支 + 兼容性目标**: 联训一个受限分支(重条件丢弃 / 低秩调色板瓶颈), 损失 = 去噪损失 + "分支残差 (分支−主) 与 已知有效的早期快照残差 对齐"。现有 SGG-BR/IG/SSG 都是中间层头且靶向 256/512px 的频率层级, 在 12-24px 上频率层级不存在。无人训练过"匹配某个快照误差方向"的分支。需训练(从 v7h 微调 20k), 是探针 2。
3. **通道解耦(alpha 轮廓 vs RGB 调色板)+ 逐步自适应的自引导权重, 并以 P/R 分解报告**: 所有自适应权重文章只做 CFG; Karras 报告引导区间会削弱自引导, 我们 gi/CADS 全劣 → 自引导正确的调度形状未知。RGBA 拆分是精灵特有的语义轴(类比 FDG 的低/高频拆分)。**零训练可测**(`--cfg_alpha`), 排 dv7h4。
4. 附: 离散/掩码扩散上的自引导无人做(v6f 分支的回收出口, 2507.08965 给出调度假设), 暂不追。

**决定**: 先把 1 和 3 的零训练版跑完(约 6 h GPU2), 按结果决定 BUILD 哪个: 若跨分辩率弱模型 ≥ 快照自引导 → 论文主机制 = "分辩率退化自引导"(纯推理, 但可加联训版 2 作强化); 若通道解耦有额外 ≥2 点 → 作为组件叠加; 若都不如快照 → 直接 BUILD 2(学习的退化分支), 快照自引导作对照线。
