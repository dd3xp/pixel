# 项目阶段规划

**制定**: 2026-08-16
**前提决定**: 代码从零构建，不以 SD-piXL 仓库为基础；到对比实验阶段（P4）才把它作为 baseline 拉进来。开发在本地（无卡），运行在 emnlp 服务器。

---

## P0 基建 + 单尺度复刻（预计 1-2 周）

从零搭出自己的最小核心，用"能复现 SD-πXL 行为"作为正确性检验。

**交付物**
- 仓库骨架：config 系统、实验目录/日志/存图约定、本地→服务器同步脚本（rsync/git）
- 可微调色板渲染器（Gumbel-softmax，按论文公式自己写，~200 行）
- SDS 损失模块（diffusers 加载 SDXL，CFG、timestep 采样、w(t) 加权，接口上预留换 teacher 的位置）
- 单尺度优化循环（16×16 直接优化）

**出口判据**：花瓣 case 单尺度跑出与 SD-piXL 相近的结果（复现"潦草"本身就是验证）。同时把 step-0→N 的细节退化曲线量化脚本写好（后面反复要用）。

**风险**：SDS 细节（噪声采样、latent 缩放、梯度权重）容易写错——对拍时可参考 SD-piXL 源码的数值行为，但不复制其代码结构。

## P1 多尺度骨架 + 核心假设验证（预计 1 周）

- 金字塔主循环：任意源尺寸 → 逐级减半 → 每级（降采样 → 调色板投影 → SDS refinement）→ 任意目标尺寸
- 先用固定调度、无锚定，最小可用版
- **关键实验**：同一批图（花瓣 + 再选 5-10 张不同题材），多尺度 vs 单尺度，同等质量判据下对比

**出口判据**：明确回答"多尺度渐进是否带来结构保持的可见优势"。是 → 继续；否 → 回到方案层反思（这是整个项目的 go/no-go 点）。

## P2 内容锚定机制（核心研究阶段，预计 3-6 周，时间大头）

- 先建诊断：每级对源图的漂移曲线、细节destruction度量（高光/色阶存活率）
- 锚定损失变体矩阵：
  - 参考对象：源图降采样版 vs 上一级结果 vs 两者加权
  - 损失形式：低频 L1 / 频带加权（低频锚布局、中频护光影）/ 特征空间（DINO/CLIP）/ 边缘图
  - 平衡策略：固定权重 / 随 timestep 退火（高噪声步让 SDS 修整，低噪声步锚定主导）/ 梯度范数归一化 / 梯度投影（SDS 分量与锚定冲突时裁剪）
- 系统消融，选出默认配置

**出口判据**：锚定多尺度在忠实度+可读性上同时优于 (a) 朴素缩小+量化、(b) 无锚定多尺度、(c) 单尺度。特别要展示"渐变/光影被保住"的对比（回应 EXP-002 的失败模式）。

## P3 自适应调度（预计 1-2 周）

- 级数：由源/目标尺寸比决定，允许内容触发插级（某级结构损失突增时）
- 每级步数：收敛判据（锚定损失 + SDS 梯度范数平台期）自动停止
- 每级 lr / timestep 范围随层级缩放
- teacher 消融在此阶段一并做：SDXL / SD1.5 / DeepFloyd 64-base（低分辨率级）/ pixel-art LoRA

**出口判据**：一套配置零手调跑通多样测试集（源图任意尺寸、目标 16²~256²）。

## P4 对比实验 + 评估体系（预计 2-3 周）

**此时才拉 SD-piXL 仓库**（服务器上已有）作为 baseline。

- 测试集构建：照片/插画/SDXL 生成图 × 目标 16/32/64/128/256
- Baselines：SD-πXL（text 模式 + image 模式）、朴素缩小+量化（含抖动版）、PixelOE、Make Your Own Sprites（有预训练则跑）
- 指标：结构保持（边缘/轮廓）、语义保真（DINO/CLIP 对源图）、色阶层次存活率、调色板协调性 + 用户研究
- 所有对比脚本化、可复跑

## P5 蒸馏前向生成器（预计 3-4 周）

- 用 P2-P3 定稿的管线批量产配对数据（8×A100 可并行，每卡 batch 跑优化）
- 前向模型：输入大图 + 调色板嵌入 → 每像素在调色板上的分类 logits（交叉熵），量化约束内建于结构
- 评估：速度（目标秒级/张）+ 相对优化结果的质量保持率

## P6 写作（与 P4/P5 并行收尾，预计 2-3 周）

- Motivation 素材已有：EXP-002 的 step0→5000 退化序列
- Related work 骨架已有：novelty_assessment.md（SD-πXL / ALPS / CSD 三个必须正面对比）
