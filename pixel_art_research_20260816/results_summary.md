# 结果汇总（V3 架构，2026-08-18）

## 最终架构（V3：风格桥接 + 残差尺度金字塔）

```
源图（任意尺寸/构图）
  ↓ [0] auto_crop 主体重构图（色度检测,中性背景;彩色背景需回退,见遗留）
  ↓ [1] 风格桥接: img2img(SDXL + pixel-art LoRA + ControlNet canny, strength 0.65)
        → 1024 高清像素画风源（描边/平涂/简化）+ 中值滤波平坦化
  ↓ [2] 残差尺度金字塔（密尾 [128,64,48,32,24,16]）:
        每级 init = 0.6·ds(上级) + 0.4·ds(风格化源)   ← 前向残差 skip
        每级锚定全程在线（λ 0.5→2.5 递增,梯度归一化合成）← 治 128 花屏
        SDS: nearest 放大 + prompt 分层（忠实→抽象）+ 低层 CFG20
        末级 2000 步（SDS 需千级步数才有方向性）
  ↓ [3] 终层合成: bg_snap 铺底 + 色彩感知 despeckle(阈0.9)
16×16 像素画（严格调色板）
```

## 全程关键发现（论文素材索引）

1. 单尺度 SDS 在 16×16 主动破坏细节（EXP-002/003）
2. 多尺度金字塔有效,密尾调度单调更优（EXP-004, P2b）
3. SDS/锚定梯度量级失衡,需归一化合成（EXP-028）
4. teacher 双盲：bilinear 糊团 + 无图像条件（EXP-050s）
5. SDS 需千级步数才有方向性;末级不足=走过场（EXP-058）
6. 清理算子会误杀单像素光影,需色彩感知（EXP-059~063）
7. 极限压缩=语义抽象问题：重构图/背景取舍/prompt 分层（P2c, auto_crop）
8. **风格差距应在高分辨率端解决**（用户提出,V3 定义性改动）
9. **链式金字塔需残差 skip 防漂移,全程锚定治花屏**（用户提出）
10. 预处理组件毒性与内容相关,需自适应门控（tone/gap 教训）

## 遗留/距投稿差距（诚实清单）

- auto_crop 彩色背景误裁（需亮度回退或分割模型）；mask 仍是 oracle 椭圆（需 SAM/U2-Net）
- prompt 表手写（需 BLIP 自动 caption + 逐色精确描述）
- 测试集 8 图,需扩到 30+ 并做用户研究/定量指标（DINO 相似度、色阶存活率已有脚本）
- seed 鲁棒性仅双花验证,V3 配方需全测试集 ×3 seed
- 单张端到端耗时 ~20 分钟（stylize 1min + 压缩 15min+）,P3 自适应停止可压缩
- 蒸馏前向生成器（P5）未动
